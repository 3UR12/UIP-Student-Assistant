# License decision pending

UIP Student Assistant `v0.5.0` no incluye una licencia pública porque el repositorio continúa siendo privado y el propietario todavía no ha seleccionado términos generales de redistribución.

Compartir una copia de la extensión con personas específicas para prueba o uso autorizado no convierte el proyecto automáticamente en software open source ni concede derechos generales sobre el código fuente.

Antes de hacer público el repositorio o permitir redistribución general, el propietario debe elegir una licencia de forma intencional.

Opciones comunes:

- **MIT:** reutilización permisiva con atribución y sin garantía.
- **Apache-2.0:** reutilización permisiva con una concesión explícita de patentes.
- **GPL-3.0:** exige que trabajos derivados distribuidos mantengan una licencia compatible GPL.
- **Propietaria / sin licencia pública:** conserva los derechos exclusivos y limita la reutilización.

Para pruebas privadas actuales, el flujo recomendado es generar un ZIP con `scripts/package-extension.ps1` y compartir únicamente ese paquete con los usuarios autorizados.

Este documento es informativo y no constituye asesoría legal. Añade un archivo `LICENSE` sólo después de confirmar los términos que realmente quieres aplicar al proyecto.
