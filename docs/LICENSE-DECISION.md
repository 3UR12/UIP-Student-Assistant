# License decision pending

No license is included in v0.1.0 because the repository is private and the project owner has not selected redistribution terms.

Before making the project public, the owner should choose intentionally:

- **MIT:** simple, permissive reuse with attribution and no warranty.
- **Apache-2.0:** permissive reuse plus an explicit patent grant.
- **GPL-3.0:** requires derivative distributed works to remain under GPL terms.
- **Proprietary / no public license:** retains exclusive rights and limits reuse.

This document is informational and is not legal advice. Add a `LICENSE` file only after the owner confirms the intended terms.
